# Keyword / SEO data providers for Italian keyword volumes — pricing and API fit (August 2026)

Goal: find an affordable API that returns Italian (Google.it) monthly search volumes, CPC, and difficulty for arbitrary keyword lists, callable from scripts, to close the "Italian keyword search volumes are unmeasured" gap in the idea-validation skill.

Reference workload used for cost estimates throughout: **200 Italian keywords with volumes + 20 SERP pulls**, one validation run.

## Per-provider notes

### SEOZoom
API access is gated to the **Evolution** plan and above — not included on the entry Essential plan (€69/mo month-to-month or €56/mo annual). Evolution costs €99 + IVA/mo month-to-month or **€76 + IVA/mo billed annually** (€910/year), confirming the figure in the brief. Every active-plan user gets 6,500 free API units/day, with pay-as-you-go top-ups purchasable in-app once exceeded — but SEOZoom does not publish the €/unit rate for that overflow anywhere public. The API (documented at apidoc.seozoom.it) exposes keyword metrics, SERP results, SERP History, Related keywords, domain/URL analysis, and competitor data — i.e., genuine keyword-idea and SERP endpoints, not just raw volume lookups. Its dataset (10B keywords, 5 European databases, Italy-only AI-visibility layer) is the most Italy-native of everything reviewed.
Source: https://www.seozoom.it/prezzi/ (2026-01-20, high), https://www.seozoom.com/buy-a-plan/ (2026-03-10, high), https://www.seozoom.com/seozoom-api-guide/ (2024-01-05, high for mechanics, may be stale on which plans include API — the 2024 article says API is available on "any active plan," but the current 2026 pricing/comparison pages explicitly list "Accesso SEOZoom API" only under Evolution-and-up features. Treat the 2026 pricing page as authoritative.)

### DataForSEO
Pure pay-as-you-go, $50 minimum deposit, no subscription. For the reference run: Google Ads API (Keywords Data) search volume costs $0.06 per task of up to 1,000 keywords (standard queue) — so 200 Italian keywords is a single $0.06 task. If richer metrics are wanted (search intent, difficulty, historical trend), DataForSEO Labs' Keyword Overview endpoint costs $0.12/task + $0.0012/item ($0.36 for 200 keywords). SERP pulls cost $0.0006/SERP on the standard queue (5-minute turnaround) up to $0.002/SERP in live mode — 20 pulls costs $0.012–$0.04. A full run lands well under $0.50; the real "cost" is the $50 floor to open an account, which at these rates covers well over 100 runs. Italian location/language support is fully confirmed via the `locations_and_languages` endpoint (Italy is one of ~100+ combinations with both `google` and `bing` sources).
Source: https://dataforseo.com/pricing/keywords-data/google-ads (fetched 2026-08-14, high), https://dataforseo.com/pricing/serp/google-organic-serp-api (fetched 2026-08-14, high), https://dataforseo.com/pricing (min deposit, high), https://docs.dataforseo.com/v3/dataforseo_labs_locations_and_languages/ (high)

### Semrush API
Semrush restructured its pricing in 2026 into SEO / Starter / Pro+ / Advanced tiers (replacing the older Pro/Guru/Business naming still quoted by some third-party sites). **API access now requires the "Advanced" tier**, $455.67/mo billed annually ($549/mo month-to-month) — and that unlocks the *ability* to buy API units, not any units themselves; unit packages are purchased separately with no public price list. Italy is one of Semrush's 9 "core" geographic databases (884M keywords after a 2022 accuracy overhaul, historical data back to January 2012), so data quality is solid, but the entry cost alone rules this out for a solo developer's occasional validation runs.
Source: https://www.semrush.com/pricing/seo-ai-search/ (fetched 2026-08-14, high), https://developer.semrush.com/api/get-started/api-access/ (last updated 2026-08-05, high), https://www.semrush.com/news/242767-global-updates-to-search-volume-machine-learning-algorithm/ (2022-10-10, medium, Italy DB size figure)

### Ahrefs API v3
As of a March 2026 change, direct API access starts from the **Lite plan ($129/mo)** rather than requiring Enterprise ($1,499/mo) — a major shift worth knowing about. Lite includes 100,000 API units/month and a 100-row-per-request cap; minimum cost per request is 50 units. A 200-keyword + 20-SERP run would consume roughly 1,000–1,500 units, trivial against the monthly quota. This makes Ahrefs viable for a solo developer for the first time, though $129/mo is still a real recurring cost versus DataForSEO's near-zero marginal pricing, and this research did not independently verify Ahrefs' Italian volume/CPC accuracy.
Source: https://help.ahrefs.com/en/articles/6559232-about-api-v3 (high), https://ahrefs.com/blog/ahrefs-pricing/ (2026-03-09, high), https://help.ahrefs.com/en/articles/6117209-what-s-the-difference-between-all-ahrefs-subscription-plans (medium, plan comparison table)

### Google Ads API (Keyword Planner) — free but gated
Developer tokens start with "Explorer Access" (2,880 ops/day on production accounts); to remove the tighter caps you apply for **Basic Access** (15,000 ops/day, ~5 business day review) or **Standard Access** (unlimited, ~10 business day review, generally reserved for larger tools). Keyword Planning-specific endpoints are further capped at 1 QPS. Both Basic and Standard access levels return search-volume **ranges, not exact numbers**, according to Google's own community forum staff replies — this is a real limitation regardless of access tier. Community/blog sources (not Google's official docs) report that accounts need roughly $50–$100 of recent ad spend before Keyword Planner endpoints return tighter, more granular ranges; Google does not document this threshold publicly, so treat it as anecdotal. Net effect: free in dollar terms, but requires maintaining a live spending Google Ads account and clearing a multi-day approval process — a real cost in time and campaign spend, not suitable for a "just call an API" workflow.
Source: https://developers.google.com/google-ads/api/docs/access-levels (high), https://developers.google.com/google-ads/api/docs/best-practices/quotas (high), https://groups.google.com/g/adwords-api/c/VvMifcYRF2g (Google staff reply on a public forum, medium), https://www.get-ryze.ai/blog/google-ads-api-keyword-planner-claude (2026-04-11, third-party blog, medium — the $50–100 spend threshold claim)

### Keywords Everywhere
Since June 2025, every plan tier (including entry-level Bronze) includes full REST API + MCP access at no extra fee — a real change from its history as an extension-only tool. Bronze is $84/year (100,000 credits), Get Keyword Data costs 1 credit per keyword (so 200 keywords = 200 credits, negligible against the annual allowance). It is keyword-metrics-only: no SERP endpoint, so it cannot cover the "20 SERP pulls" half of the reference workload on its own and would need pairing with a SERP API (e.g., DataForSEO or SerpApi). Its own docs describe country selection per request and cite Google Keyword Planner as the volume source, which in principle covers Italy, but a third-party API directory's supported-region list for this provider does not explicitly name Italy — worth a smoke test before relying on it.
Source: https://keywordseverywhere.com/compare-plans.html (high), https://keywordseverywhere.com/api-documentation.html (high), https://apio.sh/apis/keywords-everywhere (third-party directory, medium — region list caveat)

### Mangools / KWFinder API
The Mangools platform itself is cheap ($37.70/mo Basic, annual) and its docs (apidocs.mangools.com) list a full KWFinder endpoint set (related keywords, competitor keywords, keyword imports, SERP checker, locations). However, Mangools' own FAQ states API access for KWFinder/SERPChecker is a **separate plan, not part of ordinary subscriptions**, contact-gated with no public price. A third-party pricing aggregator claims "every paid plan includes an API token," which directly contradicts Mangools' own FAQ — this is an unresolved discrepancy; do not rely on the aggregator's claim without confirming directly with Mangools.
Source: https://mangools.com/faq (high, contradicts aggregator), https://thatmarketingbuddy.com/pricing/mangools (2026-07-08 verified date, medium, conflicting claim), https://apidocs.mangools.com/kwfinder/ (high, endpoint list only, no pricing)

### SerpApi
SerpApi is SERP-scraping only — there is no keyword-volume database product or "Keyword Planner volume add-on" anywhere on its pricing page; the brief's premise of such an add-on does not hold for this provider (see negative-result log). Pricing is subscription-only, no pay-as-you-go, ranging $25/mo (1,000 searches, $25/1k effective) to $275/mo (30,000 searches, $9.17/1k); a Free tier gives 250 searches/mo. For the 20-SERP-pull half of a validation run this is vastly oversized — you'd pay a full month's subscription for a handful of calls — making DataForSEO's true pay-as-you-go SERP API a better fit for occasional runs.
Source: https://serpapi.com/pricing (high), https://apiserpent.com/blog/serpapi-pricing-explained (2026-07-17, third-party competitor's comparison, medium — cross-checks against SerpApi's own numbers)

### Keyword.com
Primarily a rank tracker with MSV, CPC, competition, intent, and SERP features bundled into a single API response, at a genuinely competitive fully-loaded rate versus stitching together DataForSEO's SERP + Labs + Keywords Data APIs (Keyword.com's own comparison: $0.005–$0.0075/request all-in vs. $0.053–$0.093/request to replicate the same fields across three separate DataForSEO products). Its cheapest published API-only tier is $48/mo (5,000 keywords, weekly updates, Top 50 depth) — a flat monthly subscription with no per-call billing, which is a poor fit for an occasional 200-keyword/20-SERP validation run (you'd pay $48 for a task that costs cents on DataForSEO), but attractive if the skill evolves toward continuous rank tracking rather than one-off validation snapshots.
Source: https://keyword.com/api-pricing/ (high)

## Ranked recommendation

**1. DataForSEO — best €-per-Italian-volume for occasional, script-driven runs.** $50 one-time minimum deposit (no recurring subscription), confirmed native Italian location/language support, and a 200-keyword + 20-SERP run costs roughly $0.07–$0.40 depending on which endpoints are used. The $50 floor covers well over 100 validation runs at these rates. This is the clear pick if the skill calls the API sporadically rather than continuously.

**2. SEOZoom — best pick if an Italian-native UI+API combo is wanted, and a recurring subscription is acceptable.** €76 + IVA/mo (Evolution plan, billed annually) includes API access with 6,500 free daily API units, which comfortably absorbs a 200-keyword + 20-SERP run at zero marginal cost once subscribed. It's the only provider in this survey purpose-built for the Italian market (dedicated Italian AI-visibility dataset, 5 European databases), at the cost of a real monthly commitment versus DataForSEO's pay-as-you-go model.

Everything else is either too expensive to unlock (Semrush's $455.67/mo Advanced tier, Keyword.com's $48/mo minimum for a one-off run), gated behind non-public/custom pricing (Semrush's per-unit rate, Mangools' KWFinder API plan, SEOZoom's overflow rate), missing half the workload (SerpApi has no volume data; Keywords Everywhere has no SERP data), or carries real non-monetary friction (Google Ads API's multi-day approval and reported ad-spend requirement for non-ranged volumes).

## Does not exist publicly (negative-result log)

- **No published €/unit or $/unit overflow rate for SEOZoom's API beyond its 6,500 free daily units.** The provider states pay-as-you-go top-ups are purchasable in-app but does not list the rate on any public page found. (https://www.seozoom.com/seozoom-api-guide/, https://www.seozoom.com/integrations-reports-seozoom/)
- **No published $/API-unit price for Semrush.** Unit consumption mechanics (units per row, live vs. historical) are documented, but the price to buy a unit package is only visible after upgrading to the Advanced tier and viewing the in-account "Subscription info → API Units" page — never a public price list. (https://developer.semrush.com/api/get-started/api-access/)
- **No public pricing for Mangools' KWFinder/SERPChecker API plans**, and a direct contradiction between Mangools' own FAQ ("separate API plans... not part of our ordinary subscription plans") and a third-party pricing site's claim that API access is bundled into every paid tier. Neither source resolves the conflict; would need to contact Mangools directly. (https://mangools.com/faq vs. https://thatmarketingbuddy.com/pricing/mangools)
- **No "Google Keyword Planner volume add-on" product exists on SerpApi's pricing page or site**, despite this being a reasonable thing to look for given SerpApi's SERP-scraping focus. SerpApi sells SERP data only; it has no keyword-volume database of its own.
- **No official Google documentation confirms an ad-spend threshold for exact (non-ranged) Keyword Planner search volumes via the API.** This claim (roughly $50–$100 of recent spend) appears only in third-party blogs and older community-forum answers, never in Google's own Ads API developer docs, which describe the range-only behavior as applying uniformly to both Basic and Standard access levels with no spend-based exception documented.
- **No explicit, provider-published confirmation that Keywords Everywhere's API supports Italy as a named/tested locale.** Its docs allow arbitrary country selection per request and cite Google Keyword Planner as the source (which does cover Italy), but no page enumerates Italy specifically among supported countries, and a third-party API directory's region list omits it — this would need a direct API smoke-test (e.g., one Get Keyword Data call with `country: IT`) rather than trusting documentation alone.
