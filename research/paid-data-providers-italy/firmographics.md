# Paid Italian firmographic-data providers with APIs (2026)

Research date: 2026-08-14. Scope: providers of Italian company data (counts by ATECO code x province x size class, firm-level profiles, financials, professional-firm registries) that a solo developer could plausibly pay for — pay-per-call or an affordable self-serve subscription, no sales-led enterprise contract required to get a first API key and a first invoice.

## What stays free and is good enough

**ISTAT ASIA via the ISTAT/Eurostat SDMX web service** remains the right default for coarse market sizing: it's free, unlimited (rate-limited to 5 queries/minute per IP), machine-readable (SOAP or REST, SDMX 2.0/2.1), and requires no account. [istat.it/en/classifications-and-tools/sdmx-web-services](https://www.istat.it/en/classifications-and-tools/sdmx-web-services/), confirmed 2026-08-14, high confidence (ISTAT's own page).

The gap it leaves is exactly what paid spend should target: ISTAT/Eurostat Structural Business Statistics regional breakdowns publish at **NUTS-2 level (Italian region, not province)** and **2-digit NACE division** (not full ATECO code). [ec.europa.eu SBS metadata](https://ec.europa.eu/eurostat/cache/metadata/en/sbs_essbs21_it.htm), confirmed 2026-08-14, high confidence. So: use ISTAT/Eurostat for national- and region-level totals by broad sector for free, and reserve paid calls for the province x full-ATECO x size-class cross-tab that ISTAT doesn't expose — which is precisely what Openapi.com's free `dry_run` count endpoint delivers at effectively zero marginal cost for reasonable query volumes.

## Does not exist publicly (negative-result log)

- **Cerved production API pricing** — no self-serve price list published anywhere on developer.cerved.com or in secondary sources found; the only public number is "500 free trial calls," after which it's a sales conversation.
- **Atoka / SpazioDati per-credit price** — the credit mechanic (1 credit per company object with a data package) is documented in detail, but the €/credit conversion is never published; token issuance itself requires emailing sales.
- **CRIF Margo API production pricing** — sandbox is free and self-serve (OAuth2 client-credentials, instant signup), but the docs state explicitly that production pricing is obtained by contacting CRIF Support.
- **InfoCamere/Telemaco programmatic, single-price API for firmographic search** — the only "API" surface documented publicly (`accessoallebanchedati.registroimprese.it/abdo/api`) is sales-led, and the WebService/SOAP endpoints found (Titolare Effettivo via PDND, "Dati di Lavoro") are scoped to authorities and accredited professionals respectively, not general-purpose company search. The "elenchi di imprese" bulk-list product has a published per-record price but is fulfilled as a manual quote-and-deliver request per Chamber of Commerce, not a callable endpoint, and the price itself is inconsistent between the national Telemaco listino and individual local Chambers (e.g. Padova).
